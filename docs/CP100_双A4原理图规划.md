# CP100 双 A4 原理图规划

## 目标

CP100 原理图拆成两张 A4 横向图纸，器件按功能归属组织，块内连接使用短正交导线，跨页连接只使用少量同名网络标签。器件位号、库身份和 PCB 绑定必须保持全工程唯一，不能在两个页面复制同一位号。

## A4-1：电源、USB、ESP32-S3 与 IMU

页面标题：`CP100 主控、电源与姿态传感器`

从左到右分成三块：

1. **USB 与充电输入**：J1、J2、U8、U9、R20–R25、C20–C24、C28、C29、C32、C33。
2. **主控**：U6、S1、S2、R28、R31–R35、C26、C30、C34、C35。
3. **姿态传感器**：U7、R26、R27、C27。

建议布局区域（A4 原始坐标，单位 raw）：

| 功能块 | x 范围 | y 范围 | 说明 |
|---|---:|---:|---|
| USB/充电 | 100–460 | 240–720 | J1/J2 靠左边，U8/U9 居中，输入和电池线从左侧进入 |
| ESP32-S3 | 520–900 | 260–760 | U6 居中，两个侧按键靠下边，去耦电容靠 3V3/GND 引脚 |
| IMU | 940–1160 | 300–650 | U7 独立成块，I2C 和中断线朝向 ESP32 |

本页内部网络：

- USB：`VBUS`、`USB_CC1`、`USB_CC2`、`GND`。
- 充电：`BAT`、`BATT_TS`、`ILIM_SET`、`ISET_SET`、`TMR_SET`、`PGOOD_STATUS`、`CHG_STATUS`。
- 主控：`+3V3`、`BOOT`、`ESP_EN`、`BTN_A`、`BTN_B`、`LED_DATA`、`BAT_ADC`。
- IMU：`I2C_SDA`、`I2C_SCL`、`IMU_C1`、`IMU_INT1`、`IMU_INT2`、`MAG_INT`。
- 电源和地在本页使用少量总线/电源符号；U6 的多组 GND 脚使用两条短地干线，不能每个脚放一个 GND 符号。

## A4-2：GNSS、RF 匹配与外接天线

页面标题：`CP100 GNSS 定位与天线接口`

器件：U10、J3、L1、R29、R30、C25、C31、C34、C36。

建议布局区域：

| 功能块 | x 范围 | y 范围 | 说明 |
|---|---:|---:|---|
| GNSS 模组 | 180–650 | 300–650 | U10 居中，电源/控制在左侧，RF 在右侧 |
| 天线匹配 | 700–900 | 420–620 | L1、C36、C34 紧靠 U10 RF 脚 |
| IPEX3 座 | 960–1120 | 420–620 | J3 靠页面右边，RF 线保持最短、只转一次直角 |
| 控制与备份 | 180–650 | 700–820 | R29/R30 与备用电源去耦，避免压住模组引脚文字 |

本页内部网络：

- GNSS 射频：`GNSS_ANT`、`GNSS_ANT_BIAS`、`GNSS_ANT_NODE`。
- 模组电源：`BAT`、`+3V3`、`GND`。
- 备份与控制：`GNSS_ONOFF`、`GNSS_RESET`、`GNSS_PPS`、`GNSS_RX`、`GNSS_TX`。

## 跨页网络

跨页标签只保留以下网络，每个页面各放一个短引线加同名标签：

| 网络 | A4-1 端 | A4-2 端 | 用途 |
|---|---|---|---|
| `BAT` | 充电器 U8/J2 | U10 V_BAT | GNSS 主电源 |
| `+3V3` | U9/U6 | U10 V_BCKP、ANT_3V3 | GNSS 备份与天线偏置 |
| `GND` | 电源/主控地 | U10/J3 地 | 统一参考地 |
| `GNSS_TX` | U6 UART 输入 | U10 TXD | 定位数据接收 |
| `GNSS_RX` | U6 UART 输出 | U10 RXD | 定位数据发送 |
| `GNSS_PPS` | U6 GPIO | U10 1PPS | 秒脉冲校时 |
| `GNSS_RESET` | U6 GPIO | U10 RESET/R29 | 复位控制 |
| `GNSS_ONOFF` | U6 GPIO | U10 ON_OFF/R30 | 定位模块开关 |

`GNSS_ANT`、`GNSS_ANT_BIAS`、`GNSS_ANT_NODE` 只在 A4-2 内部连接，不能跨页，也不能用端口把 RF 线拉回主控页。

## 实施顺序

1. 保留复制得到的 P1 灯板页，器件和既有灯阵列连接不改动。
2. 在 CP100 原理图下建立 `主控电源_IMU` 与 `GNSS_RF` 两张 A4 页，按功能区放置器件。
3. 通过 pin-aware `autoconnect`、短正交导线、同名网络标签和 U6/U7 地线干线完成连线；NC 脚明确放置 no-connect 标记。
4. 每页完成 `save → doc reload → sch list → sch check → bridge-check → drc`，重载后再次回读器件数、线数和位号位置。
5. P2、P3 通过最终 gate 后再进入 PCB 更新和布线；P1 保持灯板原始页，作为像素阵列只读参考。

## 当前完成状态（2026-10-26）

- CP100 现在只有三张页：`P1`、`主控电源_IMU`、`GNSS_RF`；误建的空白 P2 页已删除。
- `主控电源_IMU`：35 个器件、129 条导线，包含 ESP32-S3、充电/电源、IMU、按键和 LED 数据接口。
- `GNSS_RF`：9 个器件、30 条导线，包含 GNSS 模块、RF 匹配、IPEX 天线座和跨页控制网络。
- P2/P3 的最终 gate 均为 `pass`：布局无重叠/出界，check 无悬空脚和真实错误，bridge-check 无桥接短路，官方 DRC 无 fatal/error。
- 图签、单页分区框和 A4 页面信息已写入；P1 只保留原灯板连接，未把历史灯阵列重画成另一套电路。
